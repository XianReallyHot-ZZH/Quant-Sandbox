## 本课目标

课 03/04 造好了机器(引擎)和刹车(风控/出场),但「研究」还没有发生:没人读样本、没跑完整策略、没有数字。本课补上编排层,对照参照物 `src/backtest/runner.py` + `src/backtest/metrics.py` + `src/risk/simulation.py`(研报 §4.2 路径 A、§3.6 #2/#3)同构复现,四条验收标准:

1. **AC1**:固定教学样本上指标值**逐值冻结断言**;
2. **AC2**:双均线 vs 买入持有**对比字段齐备**;
3. **AC3**:假设说明行**随成本/参数变化**(不许是写死的模板);
4. **AC4**:风险 findings 与运行时拦截**按 rule id 去重**有测试。

3. 参照物两套引擎的 Sharpe 都叫 `sharpe_ratio`,我们为什么必须换名字、连年度化系数都要重新选?

## 核心概念

- **M1 教学回测**(词汇表:里程碑 M1 的主体)——双均线读教学样本过**事件引擎**,产出一份 JSON-ready 的 payload:参数 / 样本 / 指标 / 成交 / 曲线 / 两类拒单 / 风控规则清单 / 假设说明行。
- **口径隔离**(ADR-0003)——事件引擎的 Sharpe 按逐 bar 权益收益计算,字段名定为 `equity_curve_sharpe`;未来滚动引擎的 Sharpe 按逐笔交易 PnL 计算,将是另一个名字。参照物两套都叫 `sharpe_ratio`、数值不可直接比较(研报 §3.6 #2),我们在**命名层**就把口径隔开。
- **指标层**(`src/backtest/metrics.py`)——Decimal 全程的最大回撤与 Calmar(纯口径:总收益% ÷ |最大回撤%|,不年度化);Sharpe 要开方,是**统计层**,float 自本课起被允许——但绝不回流账本(课 03 边界)。
- **findings 层**(`src/risk/simulation.py`)——回测后的风险复盘:运行时拦截按 rule_id 分组计数(pre_trade),复盘门再看回撤/跑赢基准/换手率(post_backtest);两层共用 `MAX_DAILY_LOSS_PCT`,运行时拦过的复盘不再重复报(研报 §3.6 #3 的坑,参照物 `simulation.py` 专门写了去重段)。
- **假设说明行**(payload 的 `assumptions`)——人类可读的中文前提声明,每一行从**真正跑过的配置**渲染:窗口、成本模型实例、K 线合成带、样本区间、指标口径、规则清单。对照参照物写死的英文模板(换了成本模型也照说 "zero fee and zero slippage"——会撒谎),这是本课的有意改进。
- **冻结断言**(票:缝 2 + 指标数值冻结)——真样本 + 固定种子数据 + 被课 03/04 测试锁死的引擎行为,三重确定性叠出一组数字,测试逐值锁死;动任何一层都该在这里红。

## 一起实现:红绿实录

本课切了七刀:策略 → 默认风控闸 → runner+指标(AC2)→ 假设行(AC3)→ 真样本冻结(AC1)→ findings 去重(AC4)→ 演示入口。与课 03(三次红全在手算)不同,这次的意外红各有各的教训:一刀红在**手算错位**,一刀红在**契约形状**,冻结前还踩到一个**真实的产品缺陷**。

### 刀 2:默认风控闸(`risk.default_risk_manager`)

### 刀 3:runner + 指标层(AC2 对比字段)

- **绿**:7 passed(结构契约、AC2 逐值、参数守卫中文报错、样本装载)。

### 刀 4:假设说明行随配置变化(AC3)

- **红**:两处失败——但红的原因是**契约形状没定清**:测试用整行相等断言,实现给「运行时风控:5 条规则(…)」补了说明性后缀「,订单提交前逐条过闸、命中即拦」。后缀该不该属于契约?定案:**锁前缀**(信息在「几条规则、哪些 id」),后缀是措辞自由区。改为 `startswith` 断言后绿。
- **断言来自哪里**:票 AC3 + ADR-0005——假设行必须描述真正跑过的配置:换窗口 → 「短窗 N / 长窗 M」行变;挂 bps 费率/滑点 → 成本行变且「零费率」消失;非零成本下全仓买单被记账层拒(费用把现金打穿),`fill_rejections` 显式非空——反静默(ADR-0006),这个后果必须看得见。
- **绿**:10 passed。

### 刀 5:真教学样本指标冻结(AC1)——本课最大的坑

- **冻结仪式**:先跑默认配置(短 3 / 长 7、零成本、五规则闸)取实际值,再写进测试锁死。
- **踩到的真缺陷**:首跑出现 **1 条 fill_rejection**——2025-03-31 的全仓买单「现金不足:需要 …747,持有 …745」,差 **2×10⁻²¹**。归因:`现金 / 收盘` 的 Decimal 除法按 28 位精度舍入,**乘回价格**可能比现金高出几个最小单位——纯粹是舍入尘埃,不是钱真的不够。参照物引擎在这类异常上**静默吞单**(研报 §4.2;课 03 我们特意改成显式拒单),这个坑在参照物里根本看不见——反静默改进第一次抓到参照物的真实缺陷。
- **修法**(源头,不动账本的严格性):策略数量按 **8 位小数步长向下取整**(交易所数量步长惯例)——宁可少买一粒尘埃,不让成本越过现金。修后首跑尘埃拒单消失,入场从 04-01 提前到 03-31,重新取冻结值。
- **冻结结果与教学故事**:策略收益 **1.86%** vs 买入持有 **24.69%**,期末 10185.71,回撤 −0.81%,Calmar 2.3,Sharpe 0.77,成交 4 笔;**193 次 MAX_POSITION_PCT 拦截**——两轮往返盈利后权益 10185 > 仓位上限(= 初始本金 10000),此后每次全仓买入都被拦,策略被迫空仓坐看基准上涨。「风控前置的真实代价」与「全仓策略不能复利」都写死在这组数字里(默认闸照抄参照物,代价刻意保留)。
- **绿**:冻结测试 + 确定性测试(两遍运行 `json.dumps` 逐字节一致)通过。

### 刀 6:findings 层与 rule id 去重(AC4)

- **红**:collection error(`risk` 包不存在)。
- **断言来自哪里**:参照物 `simulation.py`——运行时拒单按 rule_id 分组计数,消息取首条理由 + 「共拦截 N 笔」;回撤 ≥ 阈值且运行时**没**拦过同 id → 补 post_backtest finding;**拦过 → 不补**(去重);跑输基准(info)、过度换手(warning);severity 阶梯:紧急停止 critical、内置四条 warning、未知 info。手造 payload 直测,另有一条端到端测试断言真样本跑出的 193 次 MAX_POSITION_PCT 分组与 STRATEGY_UNDERPERFORM 同报。
- **绿**:一次过,7 passed。

### 评审修的一轮(双轴报告之后)

Standards 轴判无硬违规,判断题修了 5 处:

1. **rule_id 字符串单一事实源**:`simulation.py` 原本字面量重抄五条 id(注释自认「改一处必须同步另一处」)→ `risk.py` 导出 `*_RULE_ID` 常量,规则类默认值与 findings 层严重度阶梯/去重键全部引用——跨层契约的字符串只写一次;
2. **SMA 唯一事实源**:runner 的 `moving_average` 与策略的 `_sma` 同一公式 → 策略侧公开 `sma()`,runner 切片委托——曲线画的均线与驱动决策的是同一条;
3. `_pct2` 名不达意(也量化权益额/比值)→ `_quantize2`;
4. 小重复提举:`maximum_drawdown` 调两遍 → 一次;`getattr(rules)` 两处 → 解析一次传入假设行;`date_by_ts.get` 两处 → `date_of` 闭包;
5. Spec 轴抓到 **ADR-0005 漏锁**:「价格样本缺失」报错与「自定义费率/滑点模型(类型名)」分支没有测试断言 → 补两条文案锁测试。

**判不修的四条**:五参结伴穿过三个私有函数(Data Clumps)——模块内私有管道,公开关键字签名正是 AC3 测试所测,捆 config 对象反而遮住缝;路径常量取自 `data.generator` 而非 `paths.py`——dataset 身份归数据生成器所有,未手拼相对路径,精神合规;「条 findings」中英混排——票面自己的术语即契约词汇;`periods_per_year` 参数——年度化系数(√252 vs 参照物 √365)本身是被文档化的口径选择,参数就是选择的载体,参照物同款。

## 关键决策与出处

- **Sharpe 改名 `equity_curve_sharpe` + √252 年度化**:ADR-0003「payload 里口径字段不可共用命名」;研报 §3.6 #2(参照物两套 Sharpe 不可直接比较)。√252 的理由:教学样本是**工作日**日线(不含周末),金融惯例 252 交易日/年;参照物用 √365(加密「全年无休」惯例)但它自己的教学样本同样只有工作日——刻意选 252 并在模块 docstring 与假设行声明。
- **最大回撤以负百分比呈现**(`-0.81` = 回撤 0.81%):对照参照物 payload 口径(研报 §4.4 实测 `maximum_drawdown_pct=-17.67%`);复盘层判断取 `abs()`,消息里报幅度(「最大回撤 17.5%」)——符号是口径,阈值不该依赖它。
- **Calmar 用「纯口径」**:总收益% ÷ |最大回撤%|,同一回测期、不年度化;零回撤记 0。出处:参照物 `runner.py` 注释 "Adapted from web3-trading's pure Calmar metric"。
- **假设行从实例渲染**:AC3;`_describe_fee/_describe_slippage` 对内置模型说人话、对不认识的自定义模型只报类型名,**绝不冒充零成本**——文案与真实配置一致是底线。
- **`fill_rejections` 进 payload**:ADR-0006 反静默;参照物教学 payload 只报风控拒单,不报记账拒单——差异写进 runner docstring。
- **`evaluate_backtest_risk` 只读 payload 三个键**(metrics/curve/risk_rejections):引擎无关的缝,后续对账桥与滚动引擎 payload 可复用同一入口。
- **买入数量按 8 位步长向下取整**:真样本踩到的除法尘埃(差 2×10⁻²¹ 被拒)修复;账本严格性不动(cost > cash 必拒),修在订单生成侧——交易所数量步长本来就是现实约束。
- **`main()` 只是演示入口**:报告组装是课 06 的职责;findings 层的 import 放在函数体内,runner 模块级不依赖它。
- **默认闸的 193 次拦截保留不修**:仓位上限 = 初始本金是参照物默认(同构优先);它让全仓策略不能复利——这是 M1 的教学结论之一,数字与 findings 如实呈现,改默认属于后续课程的实验。

## 踩过的坑

- **手算样例也要复述分母**(刀 3 的意外红)。(10909.09 − 10000)/10000 我心算成 90.91%——丢了一位小数。写冻结断言前,把「分子是什么、分母是什么」各自念一遍,大数乘除落笔。
- **Decimal 除法尘埃是真实风险**。`Decimal` 默认 28 位精度的除法,乘回原数可能高出几个最小单位——「现金/价格」型的全仓 sizing 在账本严格(不许透支)的系统里天然脆弱。参照物静默吞单,看不见;我们显式拒单,看得见,才有得修。
- **契约先定形状再写断言**(刀 4 的红)。整行相等还是前缀匹配,是两种不同的契约:前者锁死措辞(改一个字就红),后者锁信息、放开措辞。用户可见文案里「信息部分」与「措辞部分」的分界,值得在写断言前先想清楚。
- **冻结前先跑一遍,让实现参与对账**。冻结值不是从公式里推出来的,是从确定性系统里**跑**出来的——推错一位(见第一条)跑一遍就现形。
