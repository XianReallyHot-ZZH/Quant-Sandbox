# ADR-0008: 教学注释中文化(取代 ADR-0005 的注释条款)

- 状态:Accepted(2026-09-06)
- 关联:取代 ADR-0005 中「代码标识符与注释用英文」的注释半边(其用户可见文案条款不变);ADR-0001(学习优先)

## 背景

ADR-0005 定了「标识符/注释英文」,与参照物风格同构。但本项目的第一读者是
Python 初学者(所有者本人):课 03 落地后通读源码时,英文注释成为理解上的
主要摩擦点,与 ADR-0001「学习优先」的定位相抵触。文案(运行时契约)那半边
不受影响——测试断言锁死的中文报错/输出一字未动。

## 决策

- 代码**注释与 docstring 一律中文**,面向初学者写得友好、详实:解释 Python
  惯用法(Protocol、dataclass、slots、Decimal、生成器、pytest 夹具等)
  与每处的「为什么」,不做英文注释的逐句直译。
- **标识符(变量/函数/类/模块名)保持英文**,与参照物及生态惯例一致,
  对照阅读仍可逐行对映。
- 用户可见文案条款维持 ADR-0005 原样:中文、被测试与 verify 锁死,
  文案变更 = 契约变更。
- 后续课程新代码的注释按本 ADR 执行;已落地代码(src/、tests/、app.py、
  verify.py)随本 ADR 一次性中文化,行为零变化(全量 pytest 与 verify
  均须保持全绿)。

## 后果

- 换来:初学者读源码的摩擦大幅下降;注释从「风格同构物」变成「教学资产」,
  与 docs/course/ 教材共同服务学习目的。
- 付出:与参照物注释风格不再同构,对照阅读时注释无法逐句对映(代码结构与
  标识符仍可逐行对照);非中文协作者门槛提高(ADR-0005 已知代价的放大)。
- 课 01 文档里「按 ADR-0005 将注释英文化」的评审实录是当时事实,不改;
  本 ADR 是课 03 之后的有意翻转,决策链完整保留。
