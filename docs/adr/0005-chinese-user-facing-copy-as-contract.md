# ADR-0005: 中文用户可见文案即运行时契约

- 状态:Accepted(2026-09-01)
- 关联:ADR-0006(安全文案被 verify 锁死);报告 §7、§8.5 #4

## 背景

参照物的大量中文字符串是运行时契约的一部分:测试断言里的边界文案与门标签、错误消息(如「策略名称不能为空」)、出场原因(`止损/止盈/移动止损/超时平仓/信号反转`)、LLM prompt(§7)。报告风险 #4:改语言等于改语义;若要国际化必须从第一天抽常量表。

## 决策

用户可见文案(安全警告、门标签、错误消息、出场原因、研究报告警告)一律**中文**,与参照物同构;代码标识符与注释用英文(同参照物风格)。不做国际化,不抽双语常量表。

## 后果

- 换来:安全文案这类「契约敏感物」对中文使用者保持最高敏感度;与参照物逐句对照零翻译成本。
- 付出:放弃了通用性——若未来出现非中文协作者,届时以新 ADR 重开,并把文案抽表作为那次变更的一部分。
- 测试断言、verify 字符串匹配、LLM prompt 中引用文案时,以本 ADR 为准:文案变更 = 契约变更,必须连带测试与 verify 同步改。
