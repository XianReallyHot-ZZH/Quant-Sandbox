# ADR-0007: LLM 集成 = 统一接口 + 无密钥确定性降级

- 状态:Accepted(2026-09-01)
- 关联:ADR-0002(零依赖离线)、ADR-0006(验收不依赖外部服务);报告 §4.5、§8.4

## 背景

参照物四处集成 LLM(研究报告信号分析、策略实验室 propose/explain/repair/diagnose、因子挖掘候选;知识图谱抽取属选修),姿态是**全面优雅降级**:无密钥时返回规则引擎基线/`deterministic_fallback` 并附中文说明,产品完整可用;有密钥时打 OpenAI 兼容端点(§4.5)。

## 决策

1. 定义单一 `LLMClient` 接口(标准库 `urllib` 实现,同参照物的 `http_client.py` 路线);端点/模型/超时/密钥全部环境变量配置。
2. 无密钥 → `deterministic_fallback`(规则引擎基线),产品功能与验收**完整可用**;有密钥 → 真实调用路径生效但默认沉默。
3. 验收(pytest + verify)永远不依赖外部 LLM 服务;LLM 路径的测试用本地 stub 端点或注入假 client。
4. 四处理集成点(知识图谱除外——选修)按同一接口与同一降级样式实现,不各造各的。

## 后果

- 换来:零依赖离线验收哲学不被 LLM 破坏;「优雅降级 + 配置面」作为一课被完整复刻。
- 付出:真实调用路径写完却在日常闲置——这是刻意的,不是浪费。
- fallback 与真实路径的输出 schema 必须一致(同一 payload 形状),否则前端/CLI 会出现两套分支——测试锁住这一点。
