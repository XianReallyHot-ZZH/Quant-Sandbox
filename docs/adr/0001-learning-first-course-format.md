# ADR-0001: 复现定位 = 学习优先、过程课程化

- 状态:Accepted(2026-09-01)
- 关联:CONTEXT.md「定位」;`docs/research/web3-quant-sandbox.md` §1、§8.6

## 背景

参照物是「Codex 交付课程」的配套可运行沙箱(§1.1),其自身生长方式就是课程式的:`src/` 三周从 0 到 114 个文件,第一版只有 35 天样本、1 策略、1 端点(§6.1)。复现它有三种可能目的:学习原理、得到自用工具、做教学产品。

## 决策

1. **学习优先**:手写指标/GP/岭回归/bootstrap/DSR 正是学习内容本身(§5.4 复杂度分布);可运行产物是「学会了」的证明。
2. **过程课程化**:构建顺序按课程设计,每张票 = 一节课 = 一个可运行、可验收的端到端切片(学 §8.6 的 Milestone 结构)。**产品本身不含教学内容**——不复刻 Academy(纯静态 10,749 行,§5.4 判定「零复杂度但工作量大」)。
3. **范围 = 九大核心功能**(行情/回测/审计/投资门/风险/因子挖掘/策略实验室/DSL/研究报告,§2.1),照 §8.6 全 16 步拓扑;知识图谱、Web3 情报、PIT 存根、最小静态页进**选修课池**,不阻塞主序。
4. **票粒度**:每票 300–800 行产品代码 + 配套测试,预计 30–45 张票;每票自包含、声明 blocking 边;M1/M2 是天然休止点。

## 后果

- 拒绝了「用 pandas/scipy 快速得到工具」的路线(见 ADR-0002)。
- 前端降级为一门选修课(手写无构建静态页),React 34k 行不复刻。
- 里程碑思维优先于功能完整性思维:任何时刻停下,仓库里都是一个能跑、能 verify 的东西。
